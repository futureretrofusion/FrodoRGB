# FrodoRGB public source baseline

Detected edition: **FRF 2026 Frodo RTG v1.0.27**

Required baseline characteristics include FRFBuildConfig.h, Makefile.PiStorm060, the dedicated FrodoRGB/FRF_RGBFAST path, CyberGraphX/RTG display source, FRF cartridge code, native RGB line output, GPL COPYING, repository verification and a SHA-256 source manifest.

The local source path is deliberately not recorded in the public repository.
